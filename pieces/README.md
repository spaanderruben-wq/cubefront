# Cubefront map data

The files in this folder are the map pieces of the game Cubefront (Arnhem, the rest of Gelderland and the city maps: Utrecht,
Den Haag, Amsterdam, Rotterdam and others). They are made from open data:

- **OpenStreetMap**: © OpenStreetMap contributors. The map data in these files is derived from OpenStreetMap and is available
  under the Open Database Licence (ODbL) 1.0: https://www.openstreetmap.org/copyright
- **AHN** heights (Rijkswaterstaat and the water boards, via PDOK): CC0
- **BGT** ground cover and street objects (Kadaster and the municipalities, via PDOK): CC0
- **Terrain Tiles** (Mapzen / Tilezen on AWS Open Data; SRTM, EU-DEM / Copernicus, GEBCO and others) for the land around the maps
- **CBS** municipal and provincial borders 2025 (Centraal Bureau voor de Statistiek, via PDOK): CC BY 4.0

The game itself (its code, models, sounds and the way it builds its world) is not covered by this note: see LICENSE.
